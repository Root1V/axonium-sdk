# axonium (Rust)

Rust SDK for the Prometheus Gateway inference API.

> **Status: planned.** This crate is a placeholder with the intended design recorded in
> [`src/lib.rs`](src/lib.rs). The Python SDK is being built first as the reference implementation;
> this one follows, validated against the shared contract fixtures in [`../spec/`](../spec/).
>
> `publish = false` is set in `Cargo.toml` until there is something worth publishing.

## Installation (once released)

```bash
cargo add axonium
```

Release tags are prefixed for this monorepo: `rust/v1.2.0`.
