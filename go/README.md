# axonium (Go)

Go SDK for the Prometheus Gateway inference API.

> **Status: planned.** This module is a placeholder with the intended design recorded in
> [`axonium/doc.go`](axonium/doc.go). The Python SDK is being built first as the reference
> implementation; this one follows, validated against the shared contract fixtures in
> [`../spec/`](../spec/).

## Installation (once released)

```bash
go get github.com/Root1V/axonium-sdk/go@latest
```

The module path includes the `go/` subdirectory because this is a monorepo, and release tags are
correspondingly prefixed: `go/v1.2.0` publishes version `v1.2.0` of this module.
